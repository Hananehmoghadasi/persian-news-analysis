# تحلیل اخبار فارسی

این پروژه رو برای کارآموزی نوشتم. هدفش این بود که یه دیتاست واقعی اخبار فارسی رو بررسی کنم، کیفیتش رو ببینم و یه تحلیل ساده روش انجام بدم. خبرها از چهار منبع میان: dw، isna، tasnim و rf. مجموعاً ۱۳٬۴۵۷ خبر.

## چی کار کردم

اول داده رو با Pandas لود کردم و دیدم چه ستون‌هایی داره. بعد بررسی کردم که چند تا مقدار خالی داره، چند تا ردیف تکراری هست. داده تقریباً تمیز بود؛ فقط ۵۷ تا خانه خالی داشت که همه‌شون توی ستون تصویر و برچسب بودن.

بعد رفتم سراغ پاک‌سازی متن. یکم متن‌ها مشکل داشتن: بعضی‌هاشون `&quot;` داشتن، بعضی URL-encoded بودن، بعضی نیم‌فاصله داشتن. با Hazm و چند تا regex این‌ها رو یکدست کردم. یه سری هم آزمون نوشتم که مطمئن بشم پاک‌سازی درست کار می‌کنه.

بعد خواستم ببینم هر منبع چه واژه‌هایی بیشتر استفاده می‌کنه. اول یه فهرست stopword درست کردم (اولش خیلی کامل نبود، بعداً کامل‌ترش کردم چون واژه‌های عمومی مثل «اند» و «باید» داشتن توی خروجی می‌موندن). بعد TF-IDF رو اجرا کردم که ببینم هر منبع چه واژه‌های مخصوص خودش رو داره.

آخرش هم چند تا نمودار کشیدم و نتایج رو توی `findings.md` نوشتم.

## داده‌ها
فایل‌های main_news.csv، category_news.csv و cleaned_news.csv به دلیل حجم زیاد در این ریپو قرار ندارند. برای اجرای پروژه، فایل اصلی رو از مخزن دیتاست دریافت کنید و در همان پوشه نوت‌بوک قرار دهید.

## چند تصمیم که گرفتم
۱. تاریخ نداشتیم. خواستم نمودار زمانی بکشم ولی ستون تاریخ معتبر نبود. به‌جای اینکه از Unnamed: 0 حدس بزنم، کلاً تحلیل زمانی رو کنار گذاشتم. بهتر از این بود که یه چیز غلط نشون بدم.

۲. category_news.csv رو ادغام نکردم. این فایل فقط news_id و category_id داشت و هیچ کلید مشترکی با main_news.csv نداشت. توی نوت‌بوک یه سلول گذاشتم که هم‌پوشانی link و title رو چک کنه و نتیجه‌اش صفر بود. پس به‌جای ادغام الکی، از tags یه گروه‌بندی تقریبی ساختم و توی متن گفتم که این رسمی نیست.

۳. stopwordها رو دستی درست کردم. اولش یه لیست کوتاه داشتم، ولی وقتی خروجی رو دیدم فهمیدم واژه‌های عمومی مثل «اند» و «باید» و «قرار» توش موندن. یه بار دیگه لیست رو کامل‌تر کردم. الان دیگه خبری از این واژه‌ها توی Top-20 نیست.

۴. گروه «سایر» رو جدی گرفتم. ۳۲٪ خبرها توی گروه «سایر» افتادن چون tags معنی‌دار نبودن (بایگانی، ایران، استان‌ها، آلمان و...). این رو توی گزارش نوشتم که خواننده گول نخوره و فکر نکنه این یه موضوع واحد است.

## مشکلات این پروژه
مشکل stopword: اوایل نمی‌فهمیدم چرا واژه‌های عمومی توی خروجی می‌مونن. بعد فهمیدم چون توکن‌های مرکب مثل «شده_است» رو نشکسته بودم. یه تابع filter_tokens نوشتم که این کار رو بکنه.

نمایش فارسی توی نمودار: بدون arabic-reshaper و python-bidi نمودارها ناخوانا می‌شدن. اولش فکر می‌کردم مشکل فونت است، بعد فهمیدم مشکل direction هست.

گروه‌بندی موضوعی: tags خیلی به‌هم‌ریخته بودن. یه تابع ساده نوشتم که فقط سطح اول برچسب رو نگاه کنه. کامل نیست ولی برای این تحلیل کافیه.

اینکه چرا stopword باید دستی تنظیم بشه، نه کپی-پیست
