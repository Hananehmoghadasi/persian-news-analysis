# تحلیل اخبار فارسی

این پروژه رو برای کارآموزی نوشتم. هدفش این بود که یه دیتاست واقعی اخبار فارسی رو بررسی کنم، کیفیتش رو ببینم و یه تحلیل ساده روش انجام بدم. خبرها از چهار منبع میان: dw، isna، tasnim و rf. مجموعاً ۱۳٬۴۵۷ خبر.

## چی کار کردم

اول داده رو با Pandas لود کردم و دیدم چه ستون‌هایی داره. بعد بررسی کردم که چند تا مقدار خالی داره، چند تا ردیف تکراری هست. داده تقریباً تمیز بود؛ فقط ۵۷ تا خانه خالی داشت که همه‌شون توی ستون تصویر و برچسب بودن.

بعد رفتم سراغ پاک‌سازی متن. یکم متن‌ها مشکل داشتن: بعضی‌هاشون `&quot;` داشتن، بعضی URL-encoded بودن، بعضی نیم‌فاصله داشتن. با Hazm و چند تا regex این‌ها رو یکدست کردم. یه سری هم آزمون نوشتم که مطمئن بشم پاک‌سازی درست کار می‌کنه.

بعد خواستم ببینم هر منبع چه واژه‌هایی بیشتر استفاده می‌کنه. اول یه فهرست stopword درست کردم (اولش خیلی کامل نبود، بعداً کامل‌ترش کردم چون واژه‌های عمومی مثل «اند» و «باید» داشتن توی خروجی می‌موندن). بعد TF-IDF رو اجرا کردم که ببینم هر منبع چه واژه‌های مخصوص خودش رو داره.

آخرش هم چند تا نمودار کشیدم و نتایج رو توی `findings.md` نوشتم.

## اجرا

pip install -r requirements.txt
بعد Jupyter رو باز کن، Restart Kernel بزن و Run All. همه چیز خودش اجرا می‌شه و خروجی‌ها توی outputs/ ذخیره می‌شن.

چند تصمیم که گرفتم
۱. تاریخ نداشتیم. خواستم نمودار زمانی بکشم ولی ستون تاریخ معتبر نبود. به‌جای اینکه از Unnamed: 0 حدس بزنم، کلاً تحلیل زمانی رو کنار گذاشتم. بهتر از این بود که یه چیز غلط نشون بدم.

۲. category_news.csv رو ادغام نکردم. این فایل فقط news_id و category_id داشت و هیچ کلید مشترکی با main_news.csv نداشت. توی نوت‌بوک یه سلول گذاشتم که هم‌پوشانی link و title رو چک کنه و نتیجه‌اش صفر بود. پس به‌جای ادغام الکی، از tags یه گروه‌بندی تقریبی ساختم و توی متن گفتم که این رسمی نیست.

۳. stopwordها رو دستی درست کردم. اولش یه لیست کوتاه داشتم، ولی وقتی خروجی رو دیدم فهمیدم واژه‌های عمومی مثل «اند» و «باید» و «قرار» توش موندن. یه بار دیگه لیست رو کامل‌تر کردم. الان دیگه خبری از این واژه‌ها توی Top-20 نیست.

۴. گروه «سایر» رو جدی گرفتم. ۳۲٪ خبرها توی گروه «سایر» افتادن چون tags معنی‌دار نبودن (بایگانی، ایران، استان‌ها، آلمان و...). این رو توی گزارش نوشتم که خواننده گول نخوره و فکر نکنه این یه موضوع واحد است.

چیزهایی که سخت بود
مشکل stopword: اوایل نمی‌فهمیدم چرا واژه‌های عمومی توی خروجی می‌مونن. بعد فهمیدم چون توکن‌های مرکب مثل «شده_است» رو نشکسته بودم. یه تابع filter_tokens نوشتم که این کار رو بکنه.

نمایش فارسی توی نمودار: بدون arabic-reshaper و python-bidi نمودارها ناخوانا می‌شدن. اولش فکر می‌کردم مشکل فونت است، بعد فهمیدم مشکل direction هست.

گروه‌بندی موضوعی: tags خیلی به‌هم‌ریخته بودن. یه تابع ساده نوشتم که فقط سطح اول برچسب رو نگا کنه. کامل نیست ولی برای این تحلیل کافیه.

چیزهایی که یاد گرفتم
چطور با Pandas یه دیتاست واقعی رو بررسی کنم

تفاوت میانگین و میانه و اینکه چرا برای این داده میانه بهتره

TF-IDF چطور کار می‌کنه و چرا نباید boilerplate رو قاطیش کرد

اینکه چرا stopword باید دستی تنظیم بشه، نه کپی-پیست

محدودیت‌ها
تاریخ نداریم، پس هیچ حرفی درباره روند زمانی نمی‌زنم. گروه‌بندی موضوعی تقریبیه و باید دستی بازبینی بشه (فایل نمونه‌ها رو گذاشتم). stopwordها هم مقدماتی هستن و با لیست کامل‌تر نتیجه فرق می‌کنه. TF-IDF هم فقط تفاوت واژگانی رو نشون می‌ده، نه سبک تحریریه.
## وضعیت اجرا
همه چیز اجرا شد. بارگذاری داده، پاک‌سازی، آزمون‌ها، TF-IDF و نمودارها همه موفق بودن. بسته‌های RTL هم نصب بودن، پس نمودارهای فارسی خوانا هستن.

## محیط اجرا
Python 3.9.2، pandas 2.3.3، matplotlib 3.9.4، scikit-learn 1.6.1. Hazm و arabic-reshaper و bidi هم نصب بودن.

## یافته‌ها

**۱. داده تقریباً تمیزه.** ۱۳٬۴۵۷ ردیف و ۷ ستون. صفر ردیف کاملاً تکراری. فقط ۵۷ خانه خالی که همه‌شون توی image و tags بودن. ستون site هم هیچ مقدار خالی نداره.

**۲. چهار منبع با توزیع متعادل.** dw ۲۸٪، isna ۲۷٪، tasnim ۲۴.۴٪، rf ۲۰.۶٪. هیچ منبعی اکثریت مطلق نداره.

**۳. گروه «سایر» بزرگ‌ترین گروهه ولی یکدست نیست.** ۴٬۳۴۷ خبر (۳۲.۳٪) توی این گروه افتادن چون tags معنی‌دار نداشتن. بیشترشون بایگانی (۱٬۹۴۴)، ایران (۱٬۳۰۴)، استان‌ها (۴۸۰) و آلمان (۳۴۰) بودن. این گروه رو نباید یه موضوع واحد حساب کرد.

**۴. میانگین طول خبر ۴۰۶ واژه، میانه ۲۵۹.** فاصله زیاد بین این دو نشون می‌ده چند تا خبر خیلی بلند میانگین رو بالا کشیدن. میانه عدد صادقانه‌تریه.

**۵. ۳۴.۴٪ خبرها زیر ۱۰۰ واژه‌ان، ۷.۶٪ بالای ۱۰۰۰.** یعنی تقریباً یک‌سوم داده در حد تیتر و خلاصه‌ست.

**۶. تیترهای تکراری جدا از ردیف‌های تکراری.** ۲۲ ردیف تیتر تکراری دارن (۱۱ تیتر یکتا). این با تکراری کامل ردیف فرق داره.

**۷. واژه‌های پرتکرار بعد از stopword:** ایران (۲۹٬۹۰۵)، کرونا (۲۶٬۶۸۹)، آمریکا (۱۶٬۴۲۲)، ویروس (۱۲٬۱۰۳)، گزارش (۱۱٬۶۳۴). «گزارش» و «رئیس» و «سازمان» رو هم می‌شد حذف کرد که خودم این کار رو کردم و نتیجه تمیزتر شد.

**۸. TF-IDF برای چهار منبع اجرا شد.** هر منبع واژه‌های مخصوص خودش رو داره:
- dw: فارسی، آلمان، جمهوری، ترامپ، اروپا
- isna: ادامه، رییس، گزارش، انجام، جلسه
- rf: ایران، آقای، شنبه، کرونا، بازداشت، زندان
- tasnim: عراق، استان، گروه، صهیونیستی، انقلاب، لبنان، مقاومت

**۹. آزمون پاک‌سازی ۱۱ از ۱۱ قبول شد.** آزمون URL-encoding هم پاس شد.

## نتیجه‌گیری

چهار منبع واژه‌های متفاوتی دارن و این نشون می‌ده هر کدوم چارچوب خاص خودشون رو دارن. ولی این تفاوت‌ها فقط توصیفیه، نه مدرک سبک تحریریه یا رابطه علّی. tags برای تحلیل موضوعی آماده نیست (۳۲٪ نامتجانس)، ولی متن‌ها برای تحلیل واژگانی خوبن.

## محدودیت‌ها

تاریخ معتبر نداشتیم، پس تحلیل زمانی نکردم. گروه‌بندی موضوعی از tags تقریبیه و باید دستی چک بشه. stopwordها مقدماتی هستن. `category_news.csv` ادغام نشد چون کلید مشترک نداشت. TF-IDF هم به‌تنهایی درباره سبک تحریریه چیزی نمی‌گه.
